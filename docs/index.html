muschel

Parse bash, gate it with a permit, run it through a host you control — JVM, Node, or in the browser against a virtual fs.

Try the browser playground →

Install

;; Clojure
org.replikativ/muschel {:git/url "https://github.com/replikativ/muschel"
                       :git/sha "<sha>"}
# npm
npm install muschel

Quick taste

const m = require('muschel');
const r = m.run("echo hi | tr a-z A-Z", { host: m.nodeHost() });
console.log(r.stdout);  // → "HI\n"
